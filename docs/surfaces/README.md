# Brukarflater og API-ar

Legg dokumentasjon av kontraktar som andre utviklarar eller konsumentar møter
her. Det kan vere API-endepunkt, payload-format, hendingar, brukarflater og
åtferd ved feil. Skildre den observerbare kontrakten, og lenk til
implementasjon, testar og runbooks i staden for å kopiere detaljar.

## Førsteutkast

-   [Kafka-mottak og consumer-kontrakt](kafka.md).
-   [SMS-mottak og sending](sms.md).

Dette er utvalde inngangar, ikkje ein komplett API-katalog. Wrapperfelt med
`@AuraEnabled` er ikkje åleine dokumentasjon på at ein metode er tilgjengeleg
frå eit brukargrensesnitt.
