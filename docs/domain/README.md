# Domene

Legg dokumentasjon av domenemodellar og reglar som blir handterte av
`crm-platform-integration` her. Dette kan vere omgrep, prosessar og
arbeidsflytar som går på tvers av pakkens integrasjonar. Forklar fagomgrep
tydeleg, og lenk til relevant implementasjon eller ADR når det hjelper lesaren.
