# Arkitektur

Legg systemoversikter og dokumentasjon av arkitektur som går på tvers av fleire
funksjonar eller integrasjonar her. Dette kan vere komponent- og
avhengigheitsoversikter, dataflyt og felles tekniske mønster. Legg
enkeltståande arkitekturbeslutningar i [`../adr/`](../adr/).

## Førsteutkast

-   [Systemoversikt](systemoversikt.md): komponentar og pakkegrenser.
-   [Repositorystruktur](repositorystruktur.md): kjelde- og dokumentasjonsområde.
-   [Datamodell og konfigurasjon](datamodell.md): sentrale objekt og bindings.

Sidene byggjer på statisk kjeldelesing. Dei er ikkje verifikasjon av eit
konkret Salesforce-miljø eller vedtekne arkitekturavgjerder.
