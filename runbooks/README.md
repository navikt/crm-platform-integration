# Runbooks

Runbooks describe operational procedures that need to be repeatable and
verifiable. Add or update a runbook when a change requires manual steps,
metadata cleanup, a script to be run, or an action by Team Platforce.

Use [template.md](template.md) as a starting point. Link the runbook from the
relevant Issue or pull request and from integration documentation where useful.
Record what is planned separately from what has actually been executed; include
evidence references for completed verification without copying secrets,
credentials, or personal data into the repository.
